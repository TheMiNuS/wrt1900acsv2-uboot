# Release v7.0.0

Only supported target: Linksys WRT1900ACS v2 Rev.A00 (Shelby).

## Recommended release assets

- source archive generated by `make release`;
- `u-boot-wrt1900acsv2-v7.0.0-recovery-uart-v2026.07.kwb`;
- `u-boot-wrt1900acsv2-v7.0.0-final-uart-v2026.07.kwb`;
- `u-boot-wrt1900acsv2-v7.0.0-final-nand-v2026.07.kwb`;
- `SHA256SUMS`, configurations, metadata, and upstream-source diff;
- sanitized hardware-validation log.

## Safety notice

Test `final-uart` through `kwboot` before any NAND write. Install the
`final-nand` image only after a successful `linksys uboot check`, and only
through `linksys uboot install`.

The software is provided without warranty. Bootloader replacement is a
high-risk operation and may require BootROM serial recovery if interrupted or
performed with an incompatible image.
